    Before the first real flight

    1. Export a policy: python -m hover.suite export --checkpoint … --output policy.npz. It runs on NumPy alone, and a test checks it reproduces the simulator's observations and actions.
    2. Fit absolute positioning (Lighthouse, Loco or motion capture). The Flow deck alone drifts too much for these tasks.
    3. Bench test with propellers off: confirm 100 Hz timing and the roll, pitch and yaw signs.
    4. Hover with the Crazyflie's own controller, log the hover thrust, then hand over to the policy with a watchdog that takes control back.
    5. Climb the curriculum in order, comparing every flight against the PID baseline on the same reference.

    Full procedure: docs/deployment.md on branch hpc-gpu-setup of IzzyHuang215/drone.
